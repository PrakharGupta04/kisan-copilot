# Kisan Copilot

Multi-agent AI (CrewAI + Google ADK, linked by the A2A protocol, tools served over MCP) that gives
small farmers prioritised advice on weather, mandi prices, KCC credit and PMFBY crop insurance.
Uses synthetic farmer profiles. Not financial advice.
